# Gestor-de-Notas
O Gestor de Notas é um projeto que desenvolvemos para a Feira Técnica da escola com o objetivo de facilitar a organização de notas e informações acadêmicas. Nele, é possível gerenciar professores, projetos e avaliações de forma mais simples e organizada.

Para construir o sistema, utilizamos JavaScript e Node.js, além do MongoDB para guardar os dados. Também criamos uma interface com HTML, CSS e Bootstrap, buscando deixar a utilização do sistema mais clara e acessível.

Durante o desenvolvimento, aprendemos bastante sobre programação, criação de APIs, bancos de dados e segurança de acesso. Foi um projeto importante para colocar nossos conhecimentos em prática, enfrentar desafios reais e entender melhor como funciona a criação de um sistema completo, esse projeto foi a pedido de nosso professor da matéria de web para a feira técnica.
